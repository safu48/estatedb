Render / Cloud Deployment

  1. Using Render PostgreSQL? Render automatically sets the DATABASE_URL environment variable when you link a database to this service.
  2. Schema Initialization: Run the build script once to seed your database:

    python scripts/init_db.py

    The application also automatically runs schema setup on first boot if tables are missing.
  3. Connecting from Outside Render: Ensure DB_SSL=true or ?sslmode=require is appended to the external connection string.

Local PostgreSQL Checklist

  1. Is PostgreSQL service running? Start PostgreSQL via Services or command line.
  2. Default Port: PostgreSQL uses port 5432 by default.
  3. Run Setup Script:

    python scripts/init_db.py

    This creates tables, triggers, views, stored procedures and demo data.
  4. Start the web server:

    python run.py

Try Again

Restart the server with python run.py after starting PostgreSQL.
