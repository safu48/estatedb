SELECT a.amenity_id, a.amenity_name,
       COUNT(pa.property_id) AS usage_count
  FROM amenities a
  LEFT JOIN property_amenities pa
       ON pa.amenity_id = a.amenity_id
 GROUP BY a.amenity_id, a.amenity_name
 ORDER BY usage_count DESC, a.amenity_name
Using COUNT(pa.property_id) ensures unassigned amenities return 0 instead of counting NULLs.

Why Use Reference Tables?

Storing raw text would allow typos and inconsistent naming to pollute catalog reports.

Normalizing into dedicated lookup tables with foreign key IDs guarantees high data integrity, consistent filtering, and optimal index performance.

Many-to-many relationship: Handled via the property_amenities junction table with a composite primary key.
