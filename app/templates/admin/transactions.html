Database Execution Flow

Field / ActionManaged ByMechanism
transaction_id AUTO_INCREMENT MySQL supplies sequential primary keys automatically.
commission_amount trg_txn_commission Trigger calculates amount using active agent commission rate.
txn_date Column default DEFAULT CURRENT_TIMESTAMP from database server clock.

inquiries.status sp_record_sale Open inquiries for this property are automatically closed.
