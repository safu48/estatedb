Why Deactivation Replaces Deletion

A hard DELETE FROM users WHERE user_id = 42 fails immediately if the user has saved listings, submitted inquiries, or completed deals — because 4 separate tables reference this primary key via foreign keys. 

UPDATE users
   SET is_active = 'N'
 WHERE user_id = :id

Updating the CHAR(1) flag revokes login access without corrupting relational integrity.

Protected by CHAR(1) and CHECK (is_active IN ('Y','N')) constraint.
