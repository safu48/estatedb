Database Actions on Submit

  1. Password is salted and hashed with PBKDF2 -- plain text is never stored or logged.
  2. An INSERT into users resolves role_id via subquery (SELECT role_id FROM roles WHERE role_name = 'Customer').
  3. PostgreSQL assigns the next surrogate primary key using SERIAL.
  4. RETURNING user_id returns the generated primary key to Python.
  5. An AFTER INSERT trigger writes an audit trail into audit_log.
  6. UNIQUE constraints enforce uniqueness at the database engine level.
