Purpose of This Showcase

Project Demonstration

On real-world web pages, SQL queries execute behind the scenes. This showcase renders each SQL statement side-by-side with its live output table, making it easy to examine and grade database techniques without inspecting source code.

Every statement runs in an isolated try block so a failing query displays an error card without crashing the entire page. Nothing is cached -- refreshing re-runs all live queries against PostgreSQL.

Mutating statements (such as INSERT, UPDATE, DELETE, and sp_record_sale) are deliberately omitted from this page to avoid creating unwanted records on every page refresh.
