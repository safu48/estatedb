Database Execution Flow

sp_record_sale
  1. Validation: Checks property existence, ensures current status is not already closed, verifies positive price, and validates transaction type.
  2. Insert: Inserts a new record into transactions. AUTO_INCREMENT assigns the primary key and the BEFORE INSERT trigger (trg_txn_commission) calculates commission.
  3. Update: Changes property status to SOLD or RENTED based on transaction type.
  4. Auto-Close: Closes open inquiries for this listing automatically since the deal is finalized.
  5. Commit: Transaction commits atomically. Any unexpected error triggers a complete rollback.
Stored procedures enforce core business logic at the database layer with clean error handling.
